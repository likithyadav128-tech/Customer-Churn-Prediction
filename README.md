# 📊 Customer Churn Analysis & Prediction

A complete end-to-end **Customer Churn Analysis and Prediction** project developed using **Python, SQL, Machine Learning, and Power BI**.

This project analyzes customer behavior, identifies factors contributing to customer churn, and predicts whether a customer is likely to leave the company.

---

# 🚀 Project Overview

Customer churn is one of the biggest challenges for subscription-based businesses.

This project focuses on:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Business Analysis
- Machine Learning Model Building
- Power BI Dashboard
- Business Insights

# ▶️ How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run analysis:

```bash
python python/churn_analysis.py
```

Train the model:

```bash
python python/model_training.py
```

Predict customer churn:

```bash
python python/prediction.py
```
